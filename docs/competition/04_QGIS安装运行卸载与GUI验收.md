# QGIS 0.3 安装、运行、导出、卸载与 GUI 验收

## 1. 适用环境

- 已自动验证：QGIS 3.44.14-Solothurn / Windows；
- 插件声明兼容范围：QGIS 3.28–3.99；
- 安装包自带纯 Python NetworkX 及许可证，不需要联网安装 Python 包；
- 插件完全离线，不需要 API Key、模型、在线底图或外部服务。

## 2. 安装

1. 保留当前 QGIS 工作，建议先新建空白项目。
2. 选择“插件 → 管理并安装插件 → 从 ZIP 安装”。
3. 选择 `dist/telecom_geo_agent-0.3.0.zip`。
4. 如 QGIS 提示实验性插件，确认启用“通信工程 Agent”。
5. 检查菜单、工具栏图标和右侧 Dock 各出现一次。

不要解压后混装 0.2 与 0.3 文件；升级时使用插件管理器完成。

## 3. 运行容量场景

1. 打开 Dock 的“参数化设计”页。
2. 选择“容量不足自动绕行”。
3. 核对：A → B、24 芯、优先已有管道、禁用资产为空。
4. 点击“1. 预览参数”，核对摘要和 12 位短指纹。
5. 点击“2. 确认并执行”。
6. 状态应为“完成 · 最终 PASS”。
7. 图层树应出现独立组 `通信工程智能设计 · capacity_reroute`，包含 11 个受插件管理的图层。
8. 地图应显示低饱和公开背景、青色候选通道、橙色未批准候选线、红色 C1-017、绿色最终路线、合成 A/B 站点。

若预览后修改任一字段，“确认并执行”必须重新禁用；若仍可直接执行，记为验收失败。

## 4. 运行失败场景

1. 选择“双走廊中断明确失败”。
2. 预览后确认执行。
3. 状态应显示失败并保留错误；图层中不能出现正式最终路线。
4. 输出目录不能存在该场景的 `bom.json` 或 `final_route.geojson`。
5. 再切回成功场景，确认旧图层组被替换，没有同名图层累积。

## 5. 导出图纸

1. 先完成容量场景并得到最终 PASS。
2. 点击“导出 A3 标准图纸 PDF”。
3. 状态应显示导出完成，路径位于插件运行时 `output/pdf/`；本仓库验收副本位于 `output/pdf/通信线路参数化智能设计_标准图纸_A3.pdf`。
4. 打开 PDF，检查一页 A3 横向、地图、图例、北箭头、比例尺、参数、BOM、冲突说明、OSM/ODbL 署名和非施工声明。
5. 失败场景下导出按钮必须禁用。

## 7. 卸载与回滚

1. 在插件管理器先取消启用“通信工程 Agent”。
2. 确认菜单、工具栏、Dock 和所有带插件标记的图层组已清理；用户原有图层不得变化。
3. 需要删除时，再点击卸载。
4. 如需回滚，安装已保留且哈希已核对的 `telecom_geo_agent-0.2.0.zip`。

插件只清理自己设置了 custom property 的对象；不要通过删除整个 QGIS profile 来卸载。
