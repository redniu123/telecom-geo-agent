> 验证完成日期：2026-09-06（Asia/Shanghai）

## 1. 验证对象与边界

本报告验证“结构化参数 → 确定性选路 → 独立冲突校核 → 一次有界修复 → 最终 PASS/BOM 或明确失败 → QGIS 图层/图纸”的竞赛原型。它不验证现实运营商资产、现场可施工性、正式施工图、真实造价、用户规模或比赛获奖概率。

公开背景来自已审计 staging；仓库数据清单 SHA-256 为 `BE86CE59F204C2B6732417770090DCE2C2E6DBDD671307BB3CD2E4E82D2486B4`。分类为：848 个建筑、23 个用地、1 个水体、10 条铁路、60 条道路属于公开背景派生子集；79 个节点 + 79 条边构成派生候选网络，并额外生成 79 条纯 LineString 的 QGIS 候选通道视图；2 个站点和全部通信属性为合成。

## 4. 真实 QGIS 验证

环境：QGIS `3.44.14-Solothurn`，QGIS Python `3.12.14`。执行：

```powershell
python scripts/build_qgis_plugin.py --output-dir dist
$env:QT_QPA_PLATFORM='offscreen'
& 'G:\Program Files\QGIS 3.44.14\bin\python-qgis-ltr.bat' `
  scripts\smoke_qgis_plugin.py `
  --bundle dist\telecom_geo_agent-0.3.0.zip `
  --export-pdf output\pdf\通信线路参数化智能设计_标准图纸_A3.pdf
```

结果：退出码 `0`。真实 PyQGIS 证据：

```text
main_case=PASS
no_repair_case=PASS
failed_case_with_evidence=PASS
parse_failure_clears_stale_layers=PASS
competition_capacity=PASS pdf_bytes=395665
competition_no_path=EXPECTED_FAIL_WITH_EVIDENCE
extent_updates=9
unload_layers=0
```

最终日志中 `Warning/ERROR=0`。开发中曾出现 Layout 地图项零尺寸时先设置范围导致的 LinearRing 错误；修复为“先确定图框尺寸，再 zoomToExtent”，复跑后错误计数为 0。该失败证据没有被 Mock 或忽略。

这是无界面真实 PyQGIS smoke，证明 QGIS 类、OGR 图层、插件生命周期和 Layout 导出能运行；它不能替代可见桌面环境中的文字尺寸、点击顺序、Dock 停靠和地图交互验收。
