## 验收判定规则

- “文件存在”只能证明交付结构，不证明功能成立。
- 自动测试必须断言领域事实：问题资产、前后路线差异、最终校核、BOM 可复算、无路不出 BOM。
- PyQGIS smoke 必须使用真实 QGIS 类；普通 Python fake 只用于隔离 UI 生命周期测试。
- PDF 必须重读并渲染；XLSX 必须逐表渲染并检查公式错误。
- 人工基线、可见 QGIS UI、设计合理性、正式发布许可与比赛提交始终是未自动验证边界。
