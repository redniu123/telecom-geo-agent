# 限制、风险与待人工验证

## 已完成但有明确边界

- 三场景和结构化参数是可运行的离线确定性原型，不是通用自然语言设计系统。
- QGIS 3.44.14 的真实无界面 smoke 已通过，但没有替代可见窗口的人机验收。
- A3 PDF 已独立重读和渲染检查，但不是正式施工图。
- 工作簿公式、导出和 4 页渲染已检查，但人工基线仍为空。
- 公开背景已审计，通信资产与属性全部是合成数据。

## 产品限制

1. 只有两个端点、两条候选走廊和三个冻结场景；没有任意区域自动建网。
2. 每次最多一次 forbid/replan，不做多轮优化、候选排名或交互编辑。
3. 规则只有端点、状态、容量和显式禁用；没有权属、净距、敷设规范、风险区或光功率预算。
4. BOM 是长度分类和固定 10% 余量，不含型号、价格、损耗、接头、人工或概预算。
5. 相对成本不是货币；“优先已有管道”仅切换相对成本权重与纯长度权重。
6. 没有模型、在线 GIS、数据库、任务队列、权限、并发或生产运维能力。
7. 未实现地图点选起终点；当前只允许审计数据集中已知的 A/B 合成站点。

## 不能声称的结论

在以上人工证据完成前，不能声称：

- 效率提升达到或超过 30%；
- 手工操作减少超过 50%；
- UI 已在真实用户和所有分辨率下验收；
- 输出满足现实工程规范或可以施工；
- 系统识别了现实通信网络。

## 后续开发建议

人工验收完成后再决定下一阶段，不自动扩大范围。建议依次评估：

1. 根据实际录屏中的卡点做第二轮 UI 调整，而不是凭代码猜布局；
2. 增加可审核的地图点选端点，但仍限制在已授权数据；
3. 用更多合成拓扑做性能/失败覆盖；
4. 若要接入现实数据、在线服务或模型，另行设计授权、隐私、许可和回滚门槛。
